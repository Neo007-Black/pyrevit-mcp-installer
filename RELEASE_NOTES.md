# v1.0.0

First release of the all-in-one offline installer that connects Claude to Revit through pyRevit.

- Choose Revit versions (2019 and newer) and the method: Agent MCP or Routes
- Automatic configuration for Claude Desktop and Claude Code
- Preview, uninstall, and opt-in removal of existing setups
- Secret key on the Routes method

**Download:** `PyRevitMCP-Setup.exe` below.

**Install guide:** https://github.com/Neo007-Black/pyrevit-mcp-installer/blob/main/docs/TUTORIAL.md

The EXE is not code-signed, so Windows may show a SmartScreen warning. Check the file first.
